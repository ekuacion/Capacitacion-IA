# docs/

Documentación del equipo de Pedidos Web.

| Archivo | Unidad | Qué es |
|---|---|---|
| `plantilla-mapa-sdlc.md` | U1 | Plantilla del mapa. No la edites: cópiala como `mapa-sdlc.md`. |
| `mapa-sdlc.md` | U1 | Mapa de uso de IA en el ciclo de vida del software: qué se delega, qué revisa una persona y con qué riesgo. Versión hecha con Claude Code. |
| `mapa-sdlc sin ia.md` | U1 | Versión manual del mismo mapa, sin IA, con las mismas etapas y columnas para comparar ambas. |
| `plantilla-spec-breve.md` | U3 | Plantilla para la spec breve de la HU-02. |
| `plantilla-skill.md` | U3 | Plantilla para la Skill `documentar-modulo`. |
| `modulos/` | U3 | Documentación de cada módulo, generada con tu Skill `documentar-modulo` (por ejemplo, `ClientesService.md`). |

Los próximos documentos (diagnóstico, plan de migración, gobernanza) se agregan aquí en las unidades siguientes.
Las specs de cada historia van en `specs/`, no aquí.
