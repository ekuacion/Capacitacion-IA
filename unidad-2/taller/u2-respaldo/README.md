# u2-respaldo
Plan B del **paso 2** del taller de la Unidad 2: una spec de referencia de la HU-01, por si la tuya no queda lista. **No es una rama de Git**: es una carpeta de este repositorio.

Copia el `spec.md` a `specs/HU-01-listar-pedidos/` de **tu** repo `pedidos-web`:

```bash
# macOS, Linux o WSL
mkdir -p pedidos-web/specs/HU-01-listar-pedidos
cp material-curso-ia-desarrolladores/unidad-2/taller/u2-respaldo/specs/HU-01-listar-pedidos/spec.md pedidos-web/specs/HU-01-listar-pedidos/
```
```powershell
# Windows PowerShell
New-Item -ItemType Directory -Force pedidos-web/specs/HU-01-listar-pedidos | Out-Null
Copy-Item material-curso-ia-desarrolladores/unidad-2/taller/u2-respaldo/specs/HU-01-listar-pedidos/spec.md pedidos-web/specs/HU-01-listar-pedidos/
```
