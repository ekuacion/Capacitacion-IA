> (solo lectura); el código manda, no los comentarios. Las rutas son relativas a la raíz del proyecto.
> **Verificada = «Sí»** solo si Claudio abrió el archivo en esa línea y leyó el código (5 de 15). «Por verificar» significa que la regla
